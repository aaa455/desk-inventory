# 第三步：实例分割与清单整理

验证日期：2026 年 10 月 18 日。

## 方案与实现

复用现有环境，通过 Ultralytics 官方库使用 SAM 2.1 tiny，YOLO11n 检测框提供分割提示。没有复制 Grounded-SAM-2 的业务代码。SAM 输出的是区域与质量分数，类别和检测置信度仍来自 YOLO。另实现手动框与同一物体的前景／背景点提示，用于演示提示式分割。

权重地址为 [Ultralytics 官方 SAM 2.1 tiny](https://github.com/ultralytics/assets/releases/download/v8.3.0/sam2.1_t.pt)，文件 78,105,722 字节，SHA256 为 `3c1e81ca9b037dd39d70a014ddb9a813d6c4c4e12555420db7eaff31689bd4e3`。准备脚本先校验已有权重再决定是否下载。本步骤没有新增 Python 依赖。

## 清单与掩膜规则

按模型英文类别排除人、餐桌、椅子、沙发和床，排除项保留明细与原因，可通过配置修改或请求参数取消排除。只按类别排除，不推断空间上的桌面边界。清单包含未成功生成掩膜的检测项，避免静默漏计。

掩膜是处理尺寸的二值 PNG，保留孔洞。面积是该尺寸下的像素数量，不是实际物理面积；掩膜可以互相覆盖。检测框在方向校正后的原图坐标上。SAM 返回的提示编号用于关联实例，防止掩膜被过滤后错误配对。每次最多 50 个检测实例，每批 8 个框，防止密集图片一次占用过多显存。

## 真实 HTTP 验证

沿用第二步 [scikit-image 官方咖啡桌图片](https://raw.githubusercontent.com/scikit-image/scikit-image/v0.18.3/skimage/data/coffee.png)，SHA256 为 `cc02f8ca188b167c775a7101b5d767d1e71792cf762c33d6fa15a4599b5a8de7`。图片仅保留在本地，没有重新分发。运行 `scripts/verify_segmentation.py .tmp/coffee.png --cpu`，临时启动真实本地服务，结果保存在本地 `outputs/step3-verification`。

- 自动流程检测 3 个实例，生成 3 份非空掩膜；清单为杯子 1、勺子 1，餐桌作为排除项，`total=2`。
- 取消背景类别排除后，餐桌也计入，总数为 3。
- 大图放大到 2400×1600 后，处理尺寸为 1600×1067，清单仍为杯子 1、勺子 1，PNG 掩膜与处理图尺寸一致。
- 6 份咖啡图拼接用于检查分批流程：检测 12 个实例，12 份非空掩膜，清单为杯子 6。勺子在缩放后漏检；该拼图不属于独立真实样本，也不能证明计数准确率。
- 空白图返回空清单，不调用 SAM。随后再次处理原图，类别数量保持一致；三份掩膜与第一次的 IoU 分别约 0.9994、0.99996、1.0。
- 相同图片在 GPU 多次运行有少量边缘像素差异。检查未发现残留的图像特征或提示缓存；验证采用至少 99% 的重复掩膜重叠度，不要求逐像素相等。
- 自动框、手动框和多点提示都通过实际 HTTP 接口运行；命令行导出的 JSON、叠加图和各实例 PNG 均检查可读取，二值掩膜面积与统计一致。
- CPU 手动框分割可运行；同一提示框在 GPU 上面积约 44760 像素，CPU 上 53068 像素。查看结果发现杯内区域和勺子附近的分割不同，尚未确定底层数值差异的具体来源，不宣称跨设备像素一致。

## 视觉核对与局限

已查看自动掩膜叠加图：杯把、勺子和桌面边界基本可辨，但杯子内部有孔洞，杯子掩膜也混入少量勺子附近的区域。手动点提示可能只圈出杯内局部；点和框给出的范围不必相同，使用时需查看结果并调整提示。

SAM 无法补回 YOLO 未检出的碟子或不支持类别。默认类别排除也不能证明其他检测物体都在桌面上。当前仅验证一个真实场景和其派生图片，没有人工标注掩膜真值，不报告分割准确率。质量分数不能与类别置信度直接比较。
