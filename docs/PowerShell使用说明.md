# PowerShell 操作说明

本项目第五步按用户选择采用命令行对比，不需要网页，也不需要手动启动 Uvicorn。PowerShell 入口直接调用项目虚拟环境中的 Python；HTTP 接口保留给后续集成，日常清点无需使用。

## 第一次运行

先按 README 复用或准备项目 .venv、两个本地权重和 .env 中的视觉服务配置。在 PowerShell 中输入：

~~~powershell
Set-Location 'D:\desk inventory'
.\scripts\清点桌面.ps1 -图片 'D:\照片\桌面.jpg'
~~~

照片路径可以有空格。也可以只输入 .\scripts\清点桌面.ps1，再按提示粘贴照片完整路径，此时不要在输入内容外加引号。

命令会将照片发送到配置的视觉模型服务，可能产生费用；没有自动重试。屏幕显示两份清单、差值和各自耗时。零表示成功清单中没有该类别，“未完成”表示失败，不能把它当成零。原图 SHA256 用来核对输入。

可选参数：

~~~powershell
.\scripts\清点桌面.ps1 -图片 'D:\照片\桌面.jpg' -置信度 0.35 -去重阈值 0.45 -包含背景 -输出目录 'D:\desk inventory\outputs'
~~~

默认排除人和指定家具；-包含背景 会同时取消两种方案的排除规则。它不表示真正判断了桌面范围。模型的英文类别名精确对齐，不做模糊同义词合并。

## 查看导出结果

每次分析创建独立的 outputs/comparison-时间-随机编号 目录：

| 文件 | 内容 |
| --- | --- |
| comparison.json | 完整的两份分析、状态、摘要、模型参数、计数、掩膜和差异 |
| counts.csv | UTF-8 BOM 编码的分类计数，方便表格软件打开；失败一侧数量为空 |
| segmentation.jpg | 本地方案成功时的分割叠加图 |
| mask-编号.png | 本地方案成功且返回掩膜时导出的各实例二值图 |
| 人工清点模板.json | 人工填写的模板，初始数量全部为 null，避免把模型答案当真值 |

工具不复制保存原始照片，模型与结果不会提交到 Git。完整 JSON 中包含 PNG 掩膜 data URL，文件可能较大。每次运行不覆盖此前结果。

可以用 PowerShell 打开图片和模板：

~~~powershell
Invoke-Item 'D:\desk inventory\outputs\comparison-实际目录\segmentation.jpg'
notepad 'D:\desk inventory\outputs\comparison-实际目录\人工清点模板.json'
~~~

## 人工清点与免调用模型的评估

查看原图，把模板每条“真实数量”的 null 改为 0 到 500 的整数；不是字符串或小数。若模型列出的物体实际不存在，明确填 0。两边都漏掉的类别也要手动补充，例如：

~~~json
{"中文类别":"笔","英文类别":"pen","真实数量":2}
~~~

类别数组中的条目用逗号分隔。同一英文类别只填一次，名称用小写英文；不要修改图片摘要。空图允许类别数组为 []。不修改已保存的模型结果来迁就人工清点；同义词与类别粒度差异需要在核对说明中记录，指标按原英文类别精确计算。

填写后运行：

~~~powershell
.\scripts\清点桌面.ps1 -结果 'D:\desk inventory\outputs\comparison-实际目录\comparison.json' -人工清单 'D:\desk inventory\outputs\comparison-实际目录\人工清点模板.json' -确认人工清点
~~~

这是离线操作，不会再次读取照片、加载模型或调用付费接口。再次修改数量后，可重复执行该命令。每次创建新的 evaluation-* 目录，保存 evaluation.json 和含人工计数的 counts.csv；原分析与模板不被覆盖。

评估含义：

- 总数误差：预测总数与人工总数之差的绝对值。
- 类别误差合计：各英文类别计数差的绝对值相加。把一个杯子错认成一个碗，少计杯子 1、多计碗 1，误差合计为 2，总数误差却为 0。
- 类别平均误差：类别误差合计除以本图评估类别数量。显式保留的零数量类别也属于评估类别；没有类别时为空，不伪装成评估成功且零误差。
- 少计、多计：分别统计各类不足与多出的数量。只评估成功分支，失败分支没有误差分数。

这些是本图的计数误差，不是检测准确率、分割 IoU 或整个模型的总体准确率。

## 直接使用 Python

PowerShell 执行策略不允许运行脚本时，可以直接调用项目 Python，无需修改系统策略：

~~~powershell
.\.venv\Scripts\python.exe -B scripts/compare_image.py 'D:\照片\桌面.jpg'
.\.venv\Scripts\python.exe -B scripts/compare_image.py --evaluate-result '结果目录\comparison.json' --truth '结果目录\人工清点模板.json' --confirm-truth
~~~

Python 程序退出码：0 表示双方案成功或离线评估完成；2 表示部分或全部方案失败但结构化结果已保存；1 表示输入或文件处理失败。PowerShell 入口也保留对应失败码并给出中文提示。命令行的输入文件、阈值与人工模板会校验，单个结果文件读取上限为 128 MiB，人工模板为 256 KiB。

## 适用场景与局限

| 方案 | 适用场景 | 本项目已知局限 |
| --- | --- | --- |
| YOLO + SAM | 支持类别的重复清点，需要实例轮廓、在本机处理 | 类别有限，SAM 不会补回检测漏项；本地速度依赖硬件与是否首次加载 |
| 视觉大模型 | 希望识别更多语义类别，接收文字清点规则和不确定说明 | 依赖网络和额度，可能产生误认与漏认；不提供可靠实例轮廓 |

两种方案的总耗时组成不同：本地含预处理、加载和绘图，远程含网络与服务处理。并发执行时资源也可能相互影响；不能把本次耗时当作纯模型速度排名。第三方服务返回的模型标识和令牌用量无法由本项目独立验证。
