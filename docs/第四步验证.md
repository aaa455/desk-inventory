# 第四步：视觉大模型独立清点验证

验证日期：2026 年 10 月 18 日。

## 环境复用与实现

复用项目 Python 3.12 虚拟环境和已安装的 httpx 0.28.1，没有安装新依赖、SDK 或权重。httpx 从测试依赖提升为显式运行依赖，精确锁定文件已有同一版本，无需变化。

新增 POST /api/vision、独立模型服务、结构化输出校验、命令行导出和一次真实调用验证脚本。中文提示有版本号，返回输入摘要、请求与返回模型名、输出配置、完整文字提示、耗时和服务自报的令牌用量。不会把 YOLO / SAM 的候选、数量或类别传给视觉模型。

## 真实调用

用户提供的基础地址为 https://api.hangzhale.com/v1，模型为 gpt-6.1-sol。本地 .env 保存密钥，不进入 Git；模板不含真实密钥。

沿用第二步公开的 [scikit-image 咖啡桌图片](https://raw.githubusercontent.com/scikit-image/scikit-image/v0.18.3/skimage/data/coffee.png)，本地 600×400 PNG，没有再次下载或重新分发。只发起一次真实分析，使用 json_object、max_completion_tokens=4096、图片 detail=high、120 秒调用总时限。

运行命令：

~~~powershell
.\.venv\Scripts\python.exe -B scripts/verify_vision.py .tmp/coffee.png
~~~

脚本临时启动本地 HTTP 服务，再通过命令行工具上传照片，最后自动关闭服务。本次返回：

| 项目 | 结果 |
| --- | --- |
| 请求模型／服务返回模型 | gpt-6.1-sol / gpt-6.1-sol |
| 纳入清单 | 杯子 1、碟子 1、勺子 1，总数 3 |
| 排除项 | 桌子 1，英文 dining table |
| 模型不确定说明 | 空数组，各类别说明为空字符串 |
| 总耗时／远程 HTTP 耗时 | 13016.17 / 12984.51 毫秒 |
| 服务自报令牌 | 输入 5293、输出 104、合计 5397 |

上传文件 SHA256 为 cc02f8ca188b167c775a7101b5d767d1e71792cf762c33d6fa15a4599b5a8de7，与第三步原始样本一致。发送 PNG 的 SHA256 为 884b6c0be0f697ee5cc7604ca3a4a93647598ac120a56b1716bfadde4e9e0ad2。重新编码会改变文件字节；图片未缩放。

实际导出记录位于本地 outputs/step4-verification-1792308472623600700/report.json 及其 vision-* 子目录。图片摘要、分类明细与总数一致，命令行 JSON 可读取。不将生成结果或密钥提交进仓库；复现时使用自己的有效密钥和允许发送的图片。

查看照片可见杯子、碟子、勺子。此前传统流程输出杯子 1、勺子 1，大模型本次另列出碟子。该样本没有人工标注数据集，不能据此宣称总体准确率更高，也不能用一次请求的耗时作为基准测试。空的不确定说明仅表示模型没有报告，不代表没有错误。

服务返回的模型标识不证明第三方底层确实采用某种特定架构；实际费用以服务后台为准。本步骤未做多图稳定性评估、计费评估或压力测试，也未实现第五步界面。
